### Copy-Paste Optimization Protocols
1. **Manual Selection Preference**: Since browser clipboard security blocks the 'Copy' button on non-HTTPS connections, always structure code to be easily highlighted.
2. **EOF Separation**: Ensure `cat << 'EOF'` blocks are clearly separated from prose with double newlines.
3. **Command Concatenation**: When providing multiple terminal steps, combine them into a single executable block when possible to reduce the number of individual copy-paste actions required.
